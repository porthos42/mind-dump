MindDump captures thoughts into monthly Markdown notes in your Obsidian vault.

- Windows x64; Windows 10 build 19041 or later. No separate .NET installation required.
- **Setup.exe**: recommended per-user install; no administrator privileges required.
- **Portable.zip**: extract the entire ZIP to a writable folder and run MindDump.exe.
- MindDump starts in the system tray. Press Ctrl+Shift+Space to capture.
- Save or copy your draft, then choose tray Exit before installing or replacing files.
- Settings and vault notes survive installer uninstall/reinstall. Back up notes before upgrading.
- Downloads are currently unsigned; Windows can report an unknown publisher or block execution.
  Check the source and release origin; do not disable Windows protections globally.
- SHA256SUMS.txt covers both downloads. Compare with Get-FileHash -Algorithm SHA256.
  Checksums detect corruption; they are not a publisher signature.

This version introduces the per-user installer. Portable deployment, installation,
same-version reinstall, uninstall, and data preservation passed manual testing.
A distinct-version upgrade has not yet been tested. No automatic updater is included.
