MindDump captures thoughts into monthly Markdown notes in your Obsidian vault.

This maintenance release adds automated release builds, portable ZIP validation,
SHA-256 checksums, and tag-triggered draft GitHub Releases. Local development
builds support optional self-signing. Note capture behavior is unchanged.

- Windows x64; Windows 10 build 19041 or later. No separate .NET installation required.
- **Setup.exe**: per-user installation; no administrator privileges required.
- **Portable.zip**: extract the entire ZIP to a writable folder and run MindDump.exe.
- MindDump starts in the system tray. Press Ctrl+Shift+Space to capture.
- To upgrade from 0.1.0, save or copy any draft, choose tray Exit, then run the
  0.1.1 installer as the same Windows user. No prior uninstall is required.
- Settings, vault selection, and captured notes are retained. Back up notes before upgrading.
- For portable upgrades, exit MindDump and extract the full new ZIP to a fresh folder.
- GitHub downloads are unsigned. Windows may show an unknown publisher or SmartScreen warning.
  Optional local self-signed builds do not establish public publisher trust.
- Compare downloads with SHA256SUMS.txt using Get-FileHash -Algorithm SHA256.
  Checksums detect corruption; they are not a publisher signature.
- Updates remain manual. There is no automatic updater or MSIX package.

Manual upgrade testing from 0.1.0 to 0.1.1 passed: setup blocked while an
unsaved draft was open, then completed after tray Exit without a prior uninstall.
Vault selection and previous notes were retained, and a new capture succeeded.
